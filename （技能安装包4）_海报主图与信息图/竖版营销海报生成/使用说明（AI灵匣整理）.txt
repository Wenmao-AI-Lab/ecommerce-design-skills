# 竖版营销海报生成

> HTML 排版、矢量大字、自动渲染成图——海报允许有品味的氛围渐变，但六条「廉价感红线」一条都不许碰。

## 这个技能能做什么

**固定四段式结构**，从上到下：

1. **上部** —— 品牌名 / 标签（发布日期、版本号、活动名）+ 一个**线性图标或抽象几何标记**（禁 emoji 当图标）
2. **中部视觉中心** —— 主标题（**字越大越细**，大字用 Thin / Light 字重，靠字号 + 留白建立层级）+ 一句话副标题，用 1 个强调色高亮关键词
3. **下部信息卡片** —— 3–5 条核心卖点，每条线性图标（Lucide，stroke 1.5）+ 短句
4. **底部** —— 右下角品牌 / 二维码（SVG 占位）+ CTA 文案，**底部填满，不留死空白**

**硬红线**（与知识卡的区别：海报允许**有品味的**氛围渐变 / mesh 作背景）：禁蓝紫科技渐变、禁渐变文字（`bg-clip-text`）、禁 emoji 当图标、禁粗黑大标题、禁玻璃拟态、禁底部死空白。

## 什么时候用它

- 产品发布要一张能发朋友圈的竖版海报
- 大促活动要主视觉，主题、时间、利益点都要在
- 要把「品牌 + 一句话主张 + 3 条卖点」压成一张 1080×1920
- 要在同一套视觉下出多张系列海报（换内容不换容器）

## 需要准备什么

| 材料 | 说明 | 必需 |
|---|---|---|
| 产品 / 活动信息 | 名称、核心卖点 3–5 条、时间、价格或权益 | 是 |
| 主标题与副标题 | 主张一句话，越短越好 | 是 |
| 品牌名 / Logo | 做底部署名；有 Profile 会自动读 | 建议 |
| 二维码 | 没有就用 SVG 占位框 | 否 |

**环境**：首次需 `pip install playwright` + `playwright install chromium`。

## 操作步骤

### 第 1 步：先读设计系统（别跳）

生成前先读 card-design 的设计系统：锁配色、锁字体层级、填满画幅、去 AI 廉价感。海报可用有品味的渐变背景，但仍受上面六条红线约束。

### 第 2 步：定为 HTML

容器 `width: 1080px; height: 1920px`，居中显示，圆角裁切。字体用 Noto Sans / Serif SC 全字重（细体已装），英文用 Inter Tight。

### 第 3 步：渲染成图（勿手动截图）

```bash
python C:\Users\<你>\.qoder\shared\scripts\render_card.py ^
  --html outputs\主题名\assets\poster.html ^
  --out outputs\主题名\poster.png ^
  --full-page --width 1080 --height 1920
```

竖版海报 1080×1920 用 `--full-page`。要 2 倍高清图再加 `--scale 2`。

### 第 4 步：过一遍视觉质检

```bash
python C:\Users\<你>\.qoder\skills\card-design\scripts\card_audit.py audit -f outputs\主题名\poster.png
```

`span`（内容覆盖）应 ≥0.75、`bottom_dead` 与 `max_gap` 都应 ≤0.15，任何 FAIL 就按欠填修正阶梯补内容重渲。

## 命令速查

| 命令 | 用途 |
|---|---|
| `render_card.py --html x.html --out x.png --full-page --width 1080 --height 1920` | 渲染竖版海报 |
| `render_card.py --html x.html --out x.png --full-page --width 1080 --height 1920 --scale 2` | 出 2 倍高清母版 |
| `render_card.py --html x.html --out x.png --selector ".card" --all .card` | 一页多卡时按选择器分别截图 |
| `render_card.py --html x.html --out x.png --wait 2500` | 加长等字体加载时间 |
| `render_card.py --html x.html --out x.png --proxy http://127.0.0.1:7890` | 走代理拉 CDN 与字体 |
| `card_audit.py audit -f poster.png` | 海报版式密度质检 |

## 你会拿到什么

- 一张 1080×1920 的竖版海报 PNG（需要时另出 2 倍高清母版）
- 可复跑的 HTML 源文件（改文字重渲即可出系列海报）
- `card_audit` 的质检结论（覆盖跨度 / 死空白 / 最大空带 / 填充率 / PASS 或 FAIL）

## 完整对话案例

### 案例：手工陶瓷杯产品发布海报

**你说：** 帮我做一张产品发布海报。品牌「屿陶」，产品是手工描金马克杯，卖点是①口沿手工描金②铁斑细釉③1280℃ 高温烧成④380ml 日用容量；一句话主张「一只好杯，要先解决四件小事」；价格 ￥168。

**它做：**

1. 先定风格立场（杂志编辑 + 暖纸 Dune 配色），锁定字体与配色
2. 排出四段式 HTML：品牌条 `YUTAO · BONE CHINA · 2026` / 大标题「晨白」+ 英文副标 / 四条卖点卡 / 底部品牌 + `￥168` + CTA
3. 渲染：

```bash
python C:\...\render_card.py --html outputs\屿陶\assets\poster.html --out outputs\屿陶\poster.png --full-page --width 1080 --height 1920 --scale 2
```

4. 质检：

```bash
python C:\...\card-design\scripts\card_audit.py audit -f outputs\屿陶\poster.png
```

**你会拿到：**

```
✅ outputs\屿陶\poster.png   (2160x2880, 落盘为 2 倍图)

card_audit:
  span 0.880   bottom_dead 0.056   max_gap 0.063   fill 0.352
  bands [0.29, 0.45, 0.31, 0.35]   pass true
```

**它最后会提醒你一件事（合规）：** 初版你可能会想写「￥238 划掉 → ￥168」来制造价格锚点。它不会这么做——划线价必须有真实成交依据，凭空标一个更高的「原价」属价格欺诈。所以海报上只有单一定价 ￥168（标签 RETAIL）。

## 常见问题 FAQ

**Q1：渲染报「无法启动 chromium」？**
A：没装 Chromium，执行 `playwright install chromium` 即可（退出码 3 就是这个问题）。

**Q2：出图掉字体、样式乱了？**
A：Tailwind CDN 与 Google Fonts 走外网，拉不动时脚本只打一行 WARN 就继续渲染。离线 / 内网机器用 `--proxy`（或设 `http_proxy` / `https_proxy` 环境变量），并把 `--wait` 调大。

**Q3：`--format jpeg` 之后文件后缀没变？**
A：不会自动改。`--out` 要自己写成 `.jpg`，否则拿到的是个 `.png` 名的 jpeg 数据。

**Q4：海报底部总有一块空白过不了质检？**
A：白底商品图用 `background-size: contain` 铺进固定高度图框时，四周的白会被判成中段空洞 → FAIL。先把商品图紧裁到内容外接框再铺。实测 7 张章节卡 + 1 张海报按此返工后 0 FAIL。

**Q5：能不能用它做小红书的 1080×1440 知识卡？**
A：不能，画幅不同。本技能只做 1080×1920 竖版；横版金句卡与小红书知识卡是另外两个技能。

**Q6：产物能落在 `outputs/` 根目录吗？**
A：不能。本包规约要求产物在 `outputs/<具体主题>/` 下，主题名不许 `output`、`test`、`临时` 这类泛名，公共库 `output_paths.py` 会直接拒写。
