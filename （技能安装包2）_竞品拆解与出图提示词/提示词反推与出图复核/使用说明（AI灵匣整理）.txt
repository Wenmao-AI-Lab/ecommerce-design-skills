# 提示词反推与出图复核

> 「知道好看但说不清为什么」是复刻的第一道墙。它把参考图拆成六层结构，再拿同一把尺子量你的出图——让「像不像」「差在哪」都有据可查。

## 这个技能能做什么

**六层结构**是这套技能的核心资产，每层都给出可直接拼进提示词的短语：

| 层 | 拆什么 |
|---|---|
| 主体 | 品类 · 形态 · 材质 |
| 构图 | 景别 · 视角 · 位置 · 占比 |
| 光影 | 光源 · 方向 · 强度 · 阴影 |
| 色彩 | 主色 · 配色关系 · 饱和度 · 色温 |
| 质感 | 材质表现 · 细节强调 |
| 镜头 | 焦段感 · 景深 · 清晰度 |

反推完能组装成三件套（正向 / 负向 / 参数建议），再用 `shot_review` 把出图结果逐层比对，每层给偏差等级 + 改词建议。

## 什么时候用它

- 想复刻某张爆款图的视觉风格，但不知道该写什么提示词
- AI 出的图和参考图总有差距，说不清差在哪一层
- 要建立可复用的提示词模板库，下次换商品只改主体
- 同一批 AI 出图要先筛掉明显偏离要求的

## 需要准备什么

| 材料 | 说明 | 必需 |
|---|---|---|
| 参考图 | 一张参照图，jpg / png | 是 |
| 出图结果 | 需要复核时提供；批量用 `--dir`，别用通配符 | 复核时 |
| 品类 | 服饰 / 美妆 / 家居等，影响模板选择；不确定填 `通用` | 否 |

## 操作步骤

### 第 1 步：反推参考图

```bash
python scripts/reverse_prompt.py --image 参考图.jpg --category 服饰 --out _r/反推
```

输出六层结构，每层都是可直接拼进提示词的短语。背景面积过大导致主色偏时可加 `--ignore-bg`。

### 第 2 步：组装提示词

```bash
python scripts/prompt_builder.py --reverse _r/反推/反推结果.json --style 电商主图 --platform taobao --out _r/提示词
```

输出 `正向提示词.txt` + `负向提示词.txt` + `参数建议.json`（尺寸 / 比例 / 建议采样步数与强度区间）。提示词超模型上限时用 `--layers 主体,构图,光影` 只保留关键层。

### 第 3 步：复核出图结果

```bash
python scripts/shot_review.py --reference 参考图.jpg --dir 出图/ --out _r/复核
```

六层逐项比对，每层给偏差等级与改词建议，例如：

> 光影偏差：参考图是左上硬光，出图是顶光柔光 → 提示词加 `left-top hard light, sharp shadow`

### 第 4 步：迭代

按复核建议改词 → 重出 → 重复核，通常 2–3 轮收敛。把收敛后的提示词沉淀成模板复用。

## 命令速查

| 命令 | 用途 |
|---|---|
| `reverse_prompt.py --image 图.jpg --category 服饰 --out 目录` | 反推六层结构（`--ignore-bg` 跳过背景采样） |
| `prompt_builder.py --reverse 反推结果.json --style 电商主图 --platform taobao --out 目录` | 组装正负提示词 + 参数建议 |
| `prompt_builder.py --reverse ... --layers 主体,构图,光影` | 只保留关键层，控长度 |
| `shot_review.py --reference 参考图.jpg --dir 出图/ --out 目录` | 逐层复核出图结果 |
| `shot_review.py --reference 参考图.jpg --result a.jpg b.jpg --out 目录` | 逐个指定待复核文件 |

## 你会拿到什么

- `反推结果.json` —— 六层结构化拆解
- `正向提示词.txt` / `负向提示词.txt` / `参数建议.json`
- `复核报告.md` —— 逐层偏差等级 + 具体改词建议
- 一套可沉淀复用的提示词模板（存到你自己的 outputs 主题目录下）

## 完整对话案例

### 案例：复刻一张家居爆款图的调性

**你说：** 这张床品的爆款图我很喜欢，帮我反推出提示词，我要用在自己家的四件套上。

**它做：**

```bash
python scripts/reverse_prompt.py --image 参考图.jpg --category 家居 --out _r/反推
python scripts/prompt_builder.py --reverse _r/反推/反推结果.json --style 电商主图 --platform taobao --out _r/提示词
```

**你会拿到（节选）：**

```
【主体】棉麻四件套，平铺 + 局部堆叠，哑光织物纹理
【构图】中景平铺，正俯视，主体居中略偏下，占比约 62%
【光影】窗侧自然光，左上方 45°，柔光，长而柔的阴影
【色彩】主色米白（#EFEAE2），邻近色暖灰，低饱和，色温偏暖 5200K
【质感】着重表现织物经纬与褶皱，弱反光
【镜头】50mm 感，浅景深 f/2.0，主体清晰背景柔

正向提示词：flat lay bedding set, cotton linen, matte fabric texture,
soft window light from upper left 45 degrees, warm white #EFEAE2,
low saturation, 50mm, shallow depth of field --ar 3:4
负向提示词：harsh shadow, glossy reflection, oversaturated, deformed edges,
watermark, garbled text
参数建议：1024×1365，步数 30–40，强度 0.6–0.75
```

**接着复核你的出图：**

```bash
python scripts/shot_review.py --reference 参考图.jpg --dir 出图/ --out _r/复核
```

```
光影层   偏差：中  参考为左上 45° 柔光；出图为顶光平光
                 建议加：soft window light from upper left 45 degrees
色彩层   偏差：小
构图层   偏差：大  主体占比 38%，参考 62%
                 建议加：subject fills 60% of frame
```

**它最后会提醒：** 质感层与镜头层是量化项、无容差设置，这两层永远不出差异——想控材质别等报告替你把关。

## 常见问题 FAQ

**Q1：提示词出来后是中文还是英文？**
A：反推出来的短语是英文，直接喂英文出图模型。用中文模型需要自行翻译——**翻译时别把 hex 色值和焦段翻掉**。

**Q2：为什么复核报告里质感和镜头两层永远没有差异？**
A：因为这两层只做像素量化比较且没有设置容差项，所以永远不出差异。别指望它替你把关材质，看图还得你自己看。

**Q3：`--platform` 写错了会报错吗？**
A：不会。传不认识的写法会静默退回淘宝 / 天猫那一档参数——所以写错你不会知道，参数却变了。

**Q4：批量复核为什么说「没有待复核的出图」？**
A：Windows 下 `--result 出图/*.jpg` 的通配符不会被 shell 展开，整串被当成一个不存在的文件名丢掉了。批量请用 `--dir 出图/`。

**Q5：报告全线报「偏差大」是正常的吗？**
A：先确认参考图与出图是不是同品类、同机位。不是的话报告当然全线报偏差。

**Q6：`references/prompt_library.json` 在哪？**
A：**不随包提供**。要沉淀模板先自建目录，建议存到你自己的 outputs 主题目录下。

## 注意

- `--category` 传白名单外的品类会直接终止；不确定就用 `通用`。
- `--style` 是固定四选一，写错命令行直接报错退出；`--platform` 传不认识的写法不会报错，会静默退回淘宝 / 天猫那档参数。
- Windows 下 `--result 出图/*.jpg` 的通配符不会被展开，会被当成一个不存在的文件丢掉，最后报「没有待复核的出图」——批量请用 `--dir 出图/` 或逐个写文件名。
- 复核比的是像素量化项：质感层没有任何容差项、镜头层只比景深，所以这两层永远不出差异，别等报告替你把关材质。
- 参考图与出图不是同品类、同机位时，报告会全线报偏差，先确认两者可比再解读。
- 参考图本身光比小，光影层会给出 `soft light, diffuse shadow` 这类弱结论，属正常，不必强凑。
- 反推出来的短语是英文，直接喂英文出图模型；中文模型需自行翻译，翻译时别把 hex 色值和焦段翻掉。
- 技能文档提到的 `references/prompt_library.json` 不随包提供，沉淀模板前先自建目录，建议存到自己的 outputs 主题目录下。
- 命令里的 `scripts/` 指本技能目录下的 scripts 文件夹：在 `C:\Users\<你>\.qoder\skills\prompt-reverse\` 里开终端再跑，或把 `scripts/` 换成绝对路径。
