# 竞品视觉拆解与差异化定位

> 把「他们主图很好看」这种废话，换成一张能指出往哪儿切的量化矩阵。

## 这个技能能做什么

每张竞品图抽六个可比较的维度，然后做三件事：

| 维度 | 量的是什么 |
|---|---|
| 主色系与饱和度 | 排除四角背景后的主体主色，转 HSV 取色相与饱和 |
| 构图 | 居中 / 对角 / 三分 / 满版，按主体质心与网格线判定 |
| 主体占比 | 主体像素占画布比 |
| 文字信息密度 | 极亮与极暗像素占比，估文字面积 |
| 卖点类型分布 | 需人工看图补进 `notes`（脚本不自动识别） |
| 信任元素 | 认证 / 销量 / 评价截图，同样人工补 |

算完给你三件事：**① 竞品扎堆的维度（避开）；② 无人占的维度（可切）；③ 本方与竞品群的中心距离（越远辨识度越高）**。每条空位建议都附一句可执行动作。

## 什么时候用它

- 新品上架前，想知道同类目视觉普遍长什么样，不想盲做
- 转化率低于同行，怀疑首图没有辨识度
- 给设计师下需求前，需要一份不带主观偏好的对标依据
- 想找差异化角度，不想在同一个视觉赛道上一起卷

## 需要准备什么

| 材料 | 说明 | 必需 |
|---|---|---|
| 竞品图片 | 主图 / 详情页截图，每个竞品 1–10 张；**少于 3 个竞品没有统计意义** | 是 |
| 竞品清单 | `名称 + 价格 + 销量 + images`，JSON 或 CSV（可用 `--init` 生成模板） | 是 |
| 本方主图 | 用于算与竞品群的中心距离 | 否 |

## 操作步骤

### 第 1 步：建立竞品清单

```bash
python scripts/competitor_manifest.py --init --out 竞品/竞品清单.json
```

编辑后填入，格式：

```json
{"name":"竞品A","price":159,"sales":2300,"images":["主图1.jpg","详情页1.jpg"]}
```

填完先校验：

```bash
python scripts/competitor_manifest.py --check --manifest 竞品/竞品清单.json
```

### 第 2 步：逐张拆解

```bash
python scripts/vx_analyze.py --manifest 竞品/竞品清单.json --root 竞品/ --out _r/拆解
```

每张图抽六维，结果落 `拆解明细.json`。

### 第 3 步：生成视觉矩阵

```bash
python scripts/vx_matrix.py --detail _r/拆解/拆解明细.json --out _r/矩阵
```

输出 `竞品视觉矩阵.md`（竞品 × 维度表格）与 `竞品视觉矩阵.csv`（可直接丢进表格软件画散点）。

### 第 4 步：算空位与建议

```bash
python scripts/vx_gap.py --detail _r/拆解/拆解明细.json --ours 本方主图.jpg --out _r/空位
```

产出 `差异化空位建议.md`，每条空位附一句可执行动作。

## 命令速查

| 命令 | 用途 |
|---|---|
| `competitor_manifest.py --init --out 清单.json` | 生成清单模板 |
| `competitor_manifest.py --check --manifest 清单.json` | 校验清单（相对清单目录解析路径） |
| `vx_analyze.py --manifest 清单.json --root 竞品/ --out 拆解目录` | 逐张六维拆解 |
| `vx_matrix.py --detail 拆解明细.json --out 矩阵目录` | 出 md + csv 视觉矩阵 |
| `vx_gap.py --detail 拆解明细.json --ours 本方主图.jpg --out 空位目录` | 算空位与差异度 |

## 你会拿到什么

- `竞品视觉矩阵.md` / `竞品视觉矩阵.csv` —— 竞品 × 六维量化表
- `拆解明细.json` —— 每张图的六维原始量值
- `差异化空位建议.md` —— 扎堆维度 / 空位维度 / 中心距离，每条配动作
- 一份可复核的量化依据，替代「我觉得他们图好看」的会议吵嘴

## 完整对话案例

### 案例：手工陶瓷杯上架前的竞品对标

**你说：** 我要上一款手工描金马克杯，先把同类的竞品视觉拆一下，看还有没有能切的位置。竞品图我放在 `竞品/` 下了，5 个竞品，每个 3 张。

**它做：**

```bash
python scripts/competitor_manifest.py --init --out 竞品/竞品清单.json   # 你回填 5 个竞品
python scripts/competitor_manifest.py --check --manifest 竞品/竞品清单.json
python scripts/vx_analyze.py --manifest 竞品/竞品清单.json --root 竞品/ --out _r/拆解
python scripts/vx_matrix.py --detail _r/拆解/拆解明细.json --out _r/矩阵
python scripts/vx_gap.py --detail _r/拆解/拆解明细.json --ours 本方主图.jpg --out _r/空位
```

**你会拿到（节选）：**

```
竞品视觉矩阵（5 竞品 × 6 维）
竞品     主色相    构图    主体占比  文字密度
竞品A    暖白/低   居中    42%       18%     ← 扎堆区
竞品B    暖白/低   满版    51%       24%     ← 扎堆区
竞品C    深棕/中   对角    38%       31%
竞品D    冷白/低   居中    45%       12%
竞品E    暖白/低   三分    44%       21%     ← 扎堆区

空位：
① 文字密度 12%–31% 之间无人占——竞品要么话多要么话少，中间档空着
   动作：首图只留一个核心工艺词 + 一处参数，砍掉其余小字
② 冷白主色只有 1 家在用——手工感通常配暖色，冷白反而有辨识度
   动作：试一版冷白底，观察与「手作」定位是否冲突
③ 本方与竞品群中心距离 0.31——辨识度偏低
   动作：至少在一个维度上离开扎堆区，建议选文字密度
```

**它最后会提醒：** 卖点类型与信任背书（认证、销量、好评截图）脚本不自动识别，需要你人工看图补进 `notes` 再重跑，否则这两列是空的。

## 常见问题 FAQ

**Q1：一定要 3 个以上竞品吗？**
A：少于 3 个 `vx_gap` 会直接终止并提示补样本，不会硬给空位结论。样本太少算出来的「空位」只是噪声。

**Q2：矩阵里某一行是空的？**
A：多半是清单里 `images` 的路径相对 `--root` 写错了。`--check` 按清单文件所在目录解析，`vx_analyze` 按 `--root` 解析——两处基准不一致会出现「校验通过但拆解 0 张」。

**Q3：我要放多张图，它会全拆吗？**
A：矩阵与空位只取每个竞品 `images` 的第一张当主图。顺序放错等于拆错对象，把主图放第一个。

**Q4：主色识别偏了怎么办？**
A：脚本已排除四角背景色，但纯白底、大面积单色背景仍可能偏。可以在清单里给该竞品手工指定 `bg`。

**Q5：文字信息密度是 OCR 数出来的字数吗？**
A：不是。它按极亮 / 极暗像素占比估算，只能用于竞品之间的**横向比较**，不等于真实字数。

## 注意

- 有效竞品少于 3 个时 `vx_gap` 直接终止并提示补样本，不会硬给空位结论。
- 矩阵与空位都只取每个竞品 `images` 的第一张当主图，顺序放错等于拆错对象。
- `--check` 按清单文件所在目录解析相对路径，`vx_analyze` 按 `--root` 解析；两处基准不一致会出现「校验通过但拆解 0 张」。
- 一张竞品图都没找到时 `vx_analyze` 报错退出，先核对 `--root` 与清单里的相对路径。
- 主色已排除四角背景色，但纯白底、大面积单色背景仍可能偏，可在清单里给该竞品指定 `bg`。
- 文字信息密度按极亮 / 极暗像素占比估算，不是 OCR 真实字数，只能用于竞品横向比较。
- 卖点类型与信任背书（认证、销量、好评截图）脚本不自动识别，要人工看图补进 `notes`。
- `--init` 不覆盖已存在的清单文件，想重来先手动删掉旧 json。
- 命令里的 `scripts/` 指本技能目录下的 scripts 文件夹：在 `C:\Users\<你>\.qoder\skills\visual-competitor-audit\` 里开终端再跑，或把 `scripts/` 换成该绝对路径。
- 依赖 Pillow；输出目录由脚本自动创建，`_r/` 只是示例名，换成 `outputs/类目竞品分析/` 这类具体主题名更利于归档。
