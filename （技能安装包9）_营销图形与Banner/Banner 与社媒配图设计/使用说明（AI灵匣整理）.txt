# Banner 与社媒配图设计

> 先问清六件事，再给 2-3 套美术方向各出一版——尺寸、安全区、对比度、文字占比四条硬规则全程卡着。

## 这个技能能做什么

**它只做 Banner**，不碰视频剪辑、不做整站设计、不做印刷生产。这个边界 SKILL.md 里写得很硬。

**五步工作流：**

| 步 | 做什么 |
|---|---|
| 1 | **收需求**（`AskUserQuestion`，6 个问题） |
| 2 | **研究与定美术方向**：查尺寸/安全区参考 → 收 3-5 张构图参考 → 选出 2-3 套互补的美术方向并说明各自怎么支撑用途 |
| 3 | **各方向各出一版**：HTML/CSS 按**精确平台尺寸**搭 → 按安全区规则排版 → 选视觉来源 → 叠上标题/副文案/CTA/Logo 后核层级、安全区、对比度、裁切 |
| 4 | **导出成图**：按精确视口预览 → 截图导出 PNG → 核像素尺寸/安全区/字体加载/画质 → 超平台限值就压缩 |
| 5 | **并排给方案**：每套给「风格名 + 预览 + 设计理由 + 文件路径与尺寸」，按反馈迭代 |

**第 1 步要问清这六件事**：① 用途（社媒封面 / 广告 / 网站首屏 / 印刷 / 创意素材）② 平台或自定义尺寸 ③ 内容（标题、副文案、CTA、Logo 位置）④ 品牌（既有规范、logo 文件、色、字体）⑤ 风格偏好（不确定就给它看选项）⑥ **要几套**（默认 3 套）

| Retro/Vintage 复古 | 餐饮、手作 | 做旧质感、低饱和 |
| Glassmorphism 玻璃拟态 | SaaS、App | 磨砂玻璃、模糊、发光描边 |

| 3D/Sculptural 3D | 产品、科技 | 渲染物体、景深、投影 |

**四条会全程卡着你的硬规则（`Design Rules` 原文）：**

- **安全区**：关键内容必须在画布**中央 70-80%** 内
- **CTA**：每条 Banner **只一个**，**右下角**，高**至少 44px**，动词开头
- **排印**：**最多 2 种字体**，正文最小 **16px**，标题至少 **32px**
- **文字占比**：广告类**低于 20%**（Meta 会惩罚文字过多的素材）
- **印刷**：**300 DPI、CMYK、3-5mm 出血**
- **品牌**：只应用**你提供的、已核实的**品牌规范与资产——不许自己发明品牌规则

## 什么时候用它

- 店铺首页首屏、活动 Banner、社媒头图要一次性出多套方向
- 需要一个不靠模板、按美术方向区分的 Banner 方案
- 要做印刷幅面（易拉宝、灯箱）与屏幕幅面两套
- Instagram Story 的 9:16 与 Google Ads 的 728×90 这种极端比例要一次都要

**同包内怎么选（这三者最容易混）：**

| 你要什么 | 用哪个 |
|---|---|
| **Banner / 封面 / 头图 / 首屏**，多方向比稿 | **本技能** |
| **海报 / KV / 活动图**，要**能重出图的母版文件夹** | 「营销图形母版与多尺寸套件」 |
| **整套品牌物料**（Logo + CIP + 图标 + 演示 + Banner 都在内） | 「全案设计流程」 |

**它的边界**：不做视频剪辑、不做整站设计、不做印刷生产。

## 操作步骤

### 第 1 步：它先问你六个问题

用途 / 平台或尺寸 / 内容 / 品牌 / 风格偏好 / 要几套。**你答得越具体，方向越准。**

### 第 2 步：它读参考、定方向

读 `references/banner-sizes-and-styles.md` 拿到目标格式、安全区与合适风格，然后选出 **2-3 套互补**的美术方向，并说明每套怎么支撑你的用途。

### 第 3 步：每套方向出一版

1. **用 HTML/CSS 按精确平台尺寸搭**（不是先做一张再缩）
2. **选视觉来源**：优先你给的 / 有授权的素材 → 其次纯 CSS 造（渐变、几何形状、字体排版）→ 有图像生成能力时可以生成背景或插画，**但生成的图里不许有文字**（文字必须在 HTML 层，这样才可编辑、可访问）
3. **叠字后核四项**：层级、安全区、对比度、**在精确目标尺寸下的裁切表现**

### 第 4 步：导出成图

按精确视口预览 → 截图导出 PNG → 核像素尺寸、安全区裁切、字体加载、画质 → 超平台限值就压缩。

**输出路径约定（SKILL.md 原文）：**

```
assets/banners/{campaign}/
├── minimalist-1500x500.png
├── gradient-1500x500.png
├── bold-type-1500x500.png
├── minimalist-1080x1080.png    # 多尺寸时的第二档
└── ...
```

- 文件名用 kebab-case：`{风格}-{宽}x{高}.{扩展名}`
- 时效性活动加日期前缀：`{YYMMDD}-{风格}-{尺寸}.png`
- 一次 campaign 的所有变体放同一个文件夹

### 第 5 步：并排给方案

每套列：风格名、预览图、设计理由、文件路径与尺寸。按你的反馈迭代到通过。

### 本包实测：这个技能在本包里没被直接调用，说明书不假装它跑过

**如实说**：本包的全流程实测（轻奢陶瓷马克杯）走的是「自己写 HTML 画板 + 公共运行库 `render_card.py` 渲染」这条路线，**没有调用这个技能**。

**为什么没调**：本包的物料有强约束——米色纸面 `#f0e6d2`、描金、中文活字、印刷级字距。这类需求用**自己手写 HTML 画板**更可控（尤其是中文字距与基线，见交付物 `_tmp/poster.html`、`main_images.html`）。而这个技能的强项是**多方向比稿**：给你 2-3 套美术方向让你挑，而不是替你精修一套。

**所以本说明书只做两件事**：把 SKILL.md 的真实规则、尺寸表、风格库完整列出来（上面都是原文数据），**不编造实测数字**。

**但它有两条规则，本包在自建路线里同样执行了，可以对照：**

| 它的规则 | 本包自建路线的对应做法 |
|---|---|
| 安全区：关键内容在中央 70-80% | 主图/海报的标题与主体都留出四边安全边距（交付物 `07_过程档案/版式量化_目检复核.json` 记录了各张的横向分隔线 y 坐标，用于核版式节奏） |
| 文字对比：至少 4.5:1 | 本包落成的「文字对比最小值」口径，本项目评审记录中最差一例 **7.07:1** |
| CTA 只一个 | 海报只保留一个价格锚点 `RETAIL / ￥168`（初版的划线价 `￥238` 因属虚构原价已被「发布前质量关卡」拦下删除） |
| 只应用已核实的品牌规范 | 本包未使用任何未经核实的品牌宣称；参数占位值全部标注「以随批检测报告为准」 |

**一句话**：这个技能的**规则本身可靠且可直接照用**（尺寸表、安全区、对比度、文字占比全是硬数），但它的**执行方式（多方向比稿）与本包的自建精修路线不同**——说明书把这一点说明白，比硬凑一段"实测"更有用。

## 常见问题 FAQ

**Q1：它需要装什么依赖吗？**
A：**不需要。**SKILL.md 写明这是自包含工作流：不需要同级技能、不需要技能内脚本。尺寸与安全区指南在 `references/banner-sizes-and-styles.md`。

**Q2：没有图像生成能力，它能出图吗？**
A：能。浏览器调研、图片生成、截图工具**都是可选能力**；不可用时它会用你提供的素材 + **纯 CSS 造的视觉**（渐变、几何形状、字体排版）。**纯 CSS 一样能出很有设计感的 Banner。**

**Q3：截图能力也没有呢？**
A：SKILL.md 有明确规定：这种情况**交付 HTML/CSS 源文件，并明确标注「PNG 导出为待办」**——原文还特意写了「**rather than naming an uninstalled tool**（不要随便报一个没装的工具名）」。**这条纪律很值得记住。**

**Q4：生成的背景图里可以有文字吗？**
A：不可以。SKILL.md 明确要求**生成的视觉里不许出现文字、字母、单词**——所有文案必须在 HTML 层叠上去，这样才可编辑、可访问。

**Q5：文字占比低于 20% 是什么意思？**
A：广告类素材里，**文字所占的像素面积要低于整张图的 20%**。Meta（Facebook/Instagram）会惩罚文字过多的素材，降低投放效果。这是投放侧的硬约束。

**Q6：印刷要什么规格？**
A：**300 DPI、CMYK、3-5mm 出血**。这三项都写死在 `Design Rules` 里。

**Q7：`--` 有命令行参数吗？**
A：没有。它是纯对话型技能，参数靠 `AskUserQuestion` 收。

**Q8：和同包的「营销图形母版与多尺寸套件」到底差在哪？**
A：**差在交付形态**。本技能交的是**成品 PNG + HTML 源**；那一个交的是**成品 + 一个能重出图的母版文件夹**（内容插槽、色与字规范、导出脚本、README），适合「一整个系列只换文案不换版式」的场景。
