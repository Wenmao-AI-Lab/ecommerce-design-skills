# 带货转化营销文案

> 清晰优先、讲利益不讲功能、要具体、用用户的话、一段一论点、信任前置、CTA 给理由——七条原则，套框架但落国内语境。

## 这个技能能做什么

**六类文案，各有自己的框架与语气**：

| 类型 | 主用框架 | 语气 | 关键 |
|---|---|---|---|
| 种草文案 | 痛点-方案 / 亲测体验 | 亲切、真实、去广告感 | 场景代入、真实体验、避免硬广被限流 |
| 信息流广告 | AIDA / 4U | 直给、抓眼 | 前 1 行定生死、利益前置、CTA 明确 |
| 卖点提炼 | FAB | 精炼 | 特性→优势→利益逐条翻译，排主次 |
| 活动 / 促销 | 紧迫 + 价值锚点 | 有节奏、有紧迫感 | 力度清晰、制造紧迫、降低决策成本 |
| 详情页 | FAB + 异议处理 | 专业、可信 | 卖点分层、参数可视化、打消顾虑 |
| 落地页 / 产品页 | AIDA + 结构化版块 | 依受众 | 首屏价值主张、信任背书、单一主 CTA |

**七条核心原则**：清晰优先（3 秒内看懂在卖什么）· 讲利益不讲功能（FAB 的核心）· 要具体（「早八通勤 10 分钟出门不迟到」> 「省时高效」）· 用用户的话（镜像评论区真实说法，不用品牌自嗨词）· 一段一论点 · **信任前置**（国内决策重口碑与从众）· **CTA 要给理由**（配上为什么现在买）。

## 什么时候用它

- 详情页 / 主图要写卖点文案，但不想写成自嗨词堆砌
- 要做信息流广告，前 1 行必须是钩子
- 大促活动要一版有紧迫感的促销文案
- 有一堆参数想翻译成用户能感知的利益

**职责边界**（避免用错工具）：要整套小红书笔记（多卡片 + caption + hashtags + 去 AI + 校验全流程）找 `xhs-note-creator`；要涨粉互动内容找 `social-content`；要严格套单一框架排版的帖子找 `post-formatter`。本包未含这三个，需要时在定稿后自行重排。

## 需要准备什么

| 材料 | 说明 | 必需 |
|---|---|---|
| 文案类型 | 种草 / 信息流 / 卖点提炼 / 活动 / 详情页 / 落地页 | 是 |
| 产品与卖点 | 卖什么、核心卖点、与竞品差异、能带来什么结果 | 是 |
| 目标动作 | 下单 / 领券 / 加购 / 私信 / 到店 | 是 |
| 投放平台 | 小红书 / 抖音信息流 / 朋友圈 / 电商平台等（影响长度、语气、CTA） | 是 |
| 证据素材 | 销量、评价、成分 / 参数、案例、资质 | 有则给 |
| 受众 | 谁看、有什么消费顾虑 | 是 |

## 操作步骤

### 第 1 步：收集上下文

确认六项（类型、产品卖点、目标动作、投放场景、受众、证据），缺失项它会主动问。

### 第 2 步：定语气

按 Profile 或你的指示定调：种草偏亲切真实、信息流偏直给、活动偏紧迫、详情页偏专业。

### 第 3 步：提炼卖点（FAB）

把产品特性翻译成用户利益，排出主次。特性说「它是什么」，利益说「这对你意味着什么」。

### 第 4 步：选框架搭结构

按内容目的选框架（AIDA / PAS / FAB / 4U / BAB），再按文案类型取对应结构模板，定义见技能自带的 `references/copy-frameworks.md`。

### 第 5 步：写标题 / 钩子

产出 2–3 个备选。信息流广告的前 1 行就是生死线。

### 第 6 步：填正文

逐段推进，一段一论点；用 `references/natural-transitions.md` 保持衔接自然口语。

### 第 7 步：风格打磨 + 过两道门（强制）

按 `references/writing-style-rules.md` 抓营销文案特有的风格（讲利益、信任前置、反问 / 类比、CTA 给理由）；**去 AI 味走 text-polisher 的权威源并过门禁**：AI 味自检 **≥45/50**、综合质量 **≥35/50**，不达标先改再交付。

### 第 8 步：写 CTA

按目标动作产出 2–3 个备选，每个都配「为什么现在买」。

### 第 9 步：字数校验（有长度约束的类型必做）

```bash
python C:\Users\<你>\.qoder\shared\scripts\wordcount.py count -f outputs\主题名\copy.txt
```

读 `social_count` 与投放位字符上限比对。超限先删铺垫句和修饰语再重数（本包没有压缩技能）。

### 第 10 步：组装交付

按「输出」格式组装文案 + 关键元素标注 + 备选。

## 命令速查

| 命令 | 用途 |
|---|---|
| `wordcount.py count -f 稿.txt` | 字数统计（JSON，含 `social_count` / 中文字数 / 英文单词数） |
| `wordcount.py count -f 稿.txt --json` | 同上，纯 JSON 输出便于脚本消费 |
| `wordcount.py check -f 稿.txt --target 20 --tolerance 2` | 是否命中目标字数（报 `over` / `under` / `ok`） |
| `wordcount.py check -f 稿.txt --target 20 --metric social_count` | 指定按哪个口径判定 |
| `wordcount.py selftest` | 自检 |

## 你会拿到什么

- **主标题 / 开头钩子** + 2–3 个备选

## 完整对话案例

### 案例：手工陶瓷杯的详情页文案

**你说：** 我要给一款手工描金马克杯写详情页文案。卖点是口沿手工描金、铁斑细釉、1280℃ 高温烧成、380ml。目标动作是下单。平台是淘宝详情页。受众是 25–35 岁都市女性。

**它做：**

1. 定调：详情页偏专业可信
2. 用 FAB 把四个特性翻成利益：

| 特性 | 利益 |
|---|---|
| 口沿手工描金 | 每只金线粗细略不同，属手作痕迹 |
| 铁斑细釉 | 透光可见细密星斑，触感细腻不刮手 |
| 1280℃ 高温烧成 | 致密瓷胎不吸味，咖啡茶牛奶交替用也不串味 |
| 380ml | 一杯手冲、一碗牛奶麦片都在这个量里 |

3. 排结构：首屏一句话定位 → 痛点共鸣 → 四条卖点 → 场景 → 细节 → 参数 → 信任 → 售后
4. 过两道门（AI 味 ≥45/50、综合 ≥35/50）
5. 字数校验：

```bash
python C:\...\wordcount.py count -f outputs\屿陶\详情页文案.txt
```

**你会拿到：**

```
social_count 1828（中文字符 + 英文单词 + 数字串 + 标点，标点与 emoji 各计 1）
```

**它最后会拦你两件事：**

- 你想写「按 GB 4806.4 送检，铅镉迁移量符合限值」——**它不会写**，因为本轮参数全是占位值、没有对应批次报告，这样写属虚假宣传。它会改成「按 GB 4806.4 标准组织生产；铅镉迁移量以随批检测报告为准」。
- 你写了一句「金线粗细会有细微差异——这是手作痕迹，不是瑕疵」。**它会改掉**，因为去 AI 味规则第 2 条禁「不是 X 而是 Y」二元对比、第 6 条禁破折号。改成「会有细微差异，属手作痕迹」。

**实测复核：** 去 AI 味扫描归 0 类、合规扫描七组全 0。

## 常见问题 FAQ

**Q1：Windows 下提示 `python3` 不是内部或外部命令？**
A：把命令开头的 `python3` 换成 `python`（实测环境为 Windows + Python 3.12.10）。

**Q2：`social_count` 数出来比我手数的多？**
A：它的口径是**中文字符 + 英文单词 + 数字串 + 标点，标点和 emoji 也各计 1**，贴近微博计法。投放位写「含标点 20 字」时按这个口径比。

**Q3：`check` 为什么报 `under`？**
A：`check` 判的是「命中目标字数 ±容差」，不是「不超过上限」。只要上限时按上限当 `target` 看，报 `over` 就删字，报 `under` 不算问题。

**Q4：超字数怎么压？**
A：**本包没有压缩技能**（SKILL.md 指向的 `text-condenser` 未随包提供）。先删铺垫句和修饰语，再重数。

**Q5：去 AI 门禁报「没清单可查」？**
A：门禁依赖同包 text-polisher 的三个 references 文件，**两个技能要一起装**，否则没清单可查。

**Q6：能不能自己编一点数据让文案更有说服力？**
A：不行。证据只能来自你提供的素材。无来源的百分比、「用了 X 之后 Y 立刻改善」这类无据因果，发布前会被「发布前质量关卡」判成虚假宣传风险。

**Q7：SKILL.md 里指向的 `skills/shared/references/copy-frameworks.md` 找不到？**
A：那两个公共参考源不在本包内。框架定义与六类结构模板直接用技能自带的 `references/copy-frameworks.md` 即可；标题钩子按步骤 5 出 2–3 个备选。
