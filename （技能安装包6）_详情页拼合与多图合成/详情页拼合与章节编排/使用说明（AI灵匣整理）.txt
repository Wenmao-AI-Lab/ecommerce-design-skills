【功能描述】详情页拼合与章节编排：把分段的详情页素材（主图/卖点/场景/参数/信任背书/售后）按电商详情页的标准章节结构纵向拼合成一张长图，自动编排章节顺序、章节间距、分隔样式与高度节奏，并做切图导出与自检。当用户要「拼详情页」「详情页长图」「详情页切图」「章节编排」「详情页模块顺序」时使用。

【详细概述】



# 详情页拼合与章节编排

> 把散装的分段素材，按买家浏览的心理顺序拼成一张能直接上传的详情页长图，再按平台要求切好段。

## 这个技能能做什么

一堆散装的分段素材 → 一张顺序不错、接缝干净、高度可控、可直接上传的详情页长图，最后按平台要求切好段。它管的是**结构与几何**，不是设计。

**标准章节顺序**（代码 `pdp_build.py` 里 `STD_ORDER` 的真实定义，10 个）：

| # | 章节键 | 名称 | | # | 章节键 | 名称 |
|---|---|---|---|---|---|---|
| 1 | `hero` | 首屏主视觉 | | 6 | `detail` | 细节特写 |
| 2 | `pain` | 痛点共鸣 | | 7 | `spec` | 规格参数 |
| 3 | `selling` | 核心卖点 | | 8 | `compare` | 对比说明 |
| 4 | `scene` | 使用场景 | | 9 | `trust` | 信任背书 |
| 5 | `model` | 模特/实拍 | | 10 | `service` | 售后保障 |

清单里 `items` 的先后会被**自动重排成上表顺序**；想按自己写的顺序拼，加 `--keep-order`。非标准 `chapter` 键会被排到末尾。

**三个动作一套走完：**
1. **`--template` 生成清单模板** —— 给你一个可填的空壳，照着填图片路径与标题
2. **拼合** —— 按目标宽度等比缩放每章素材，纵向接起来，输出长图 + 章节索引（每章的起止 y、高度、标题）
3. **自检 + 切图** —— 自检查几何自洽与空白章；切图按固定段高切好，最后一段可能不足一段高

**自检查什么**（代码 `pdp_check.py` 的规则与阈值）：

| 规则 | 严重度 | 判据 |
|---|---|---|
| 总高自洽 | high | 总高 = 各章高度和 + 间距和 |
| 宽度自洽 | high | 段宽与声明一致 |
| 章节连续 | high | 相邻章节首尾相接，不脱节 |
| 章节不重叠 | high | 相邻章节区间不交叠 |
| 章节顺序 | mid | 是否落在标准结构里 |
| 非空白章 | mid | 逐行采样近空白行占比 **> 0.80** 判为疑似断层（章高 < 20px 时不做） |
| 宽度推荐 | low | `750` 淘宝/天猫/拼多多、`800` 抖音小店/京东、`1242` 小红书 |

**判定线**：只要出现 high 或 mid，`pass=False`，脚本以**退出码 1** 结束——这是「自检没过」，不是「脚本崩溃」。

## 什么时候用它

- 已有分段详情素材（多张图 / 多个模块），要拼成一张可上传的详情页长图
- 要按标准电商章节结构（首屏→痛点→卖点→场景→细节→参数→信任→售后）编排顺序
- 要把一张超长详情页切成平台可接受的分段图片
- 要统一多模块的宽度、间距、分隔样式，让整页看起来是一套的

**不适合的场景**：拼的是九宫格 / 对比图 / 一大四小这种**版式**图（那是「多图合成与导出」的活）；要审文案合规（那是「发布前质量关卡」）。

## 需要准备什么

| 材料 | 说明 | 必需 |
|---|---|---|
| 素材清单 JSON | 用 `--template` 生成模板再填 | 是 |
| 各章素材图 | 建议同宽；会按目标宽度自动等比缩放 | 是 |
| 目标宽度 | 默认 750（淘宝/天猫/拼多多标准） | 否 |
| 品牌色 | `--brand-color`，如 `#8F7650` | 否 |

**环境**：脚本随本技能自带（`scripts/` 下 4 个文件），依赖 **Pillow**（本包实测环境：Windows + Python 3.12.10 + Pillow 12.3.0，全程 rc=0）。

**注意命令写法**：技能文档里给的是裸文件名（`python pdp_build.py ...`），需先切到技能目录的 `scripts/` 下，或补全路径。

## 操作步骤

### 第 1 步：生成清单模板

```bash
python pdp_build.py --template 素材清单.json
```

模板会自带 10 个标准章节的骨架与 `brand_color` / `gap` / `divider` 三个全局项。

### 第 2 步：填清单

每个章节指定 `chapter`、`title`、`image`。图片用**绝对路径**，或相对于清单文件的路径。

### 第 3 步：拼合

```bash
python pdp_build.py --manifest 素材清单.json --out 详情页 --width 750 --brand-color "#8F7650"
```

### 第 4 步：自检

```bash
python pdp_check.py --dir 详情页 --out 检查
```

存在 high / mid 问题时会以**退出码 1** 结束，看 `详情页自检.md` 的结论行。

### 第 5 步：切图

```bash
python pdp_export.py --src 详情页/详情页长图.jpg --out 切图 --slice 1000 --idx 详情页/章节索引.json
```

`--idx` 是可选的，但**给了它，切图清单才会写出「这段覆盖了哪些章节」**；不给就只有 `-`。

## 命令速查

**`pdp_build.py`** —— 生成模板 / 拼合

| 参数 | 说明 |
|---|---|
| `--template` | 生成清单模板到指定路径 |
| `--manifest` | 素材清单 JSON |
| `--out` | 输出目录 |
| `--width` | 目标宽度，默认 750；小于 200 直接报错 |
| `--brand-color` | 品牌色 |
| `--keep-order` | 保持清单原顺序，不按标准结构重排 |

**`pdp_check.py`** —— 自检

| 参数 | 说明 |
|---|---|
| `--dir` | 拼合产物目录 |
| `--out` | 检查报告输出目录 |

**`pdp_export.py`** —— 切图

| 参数 | 说明 |
|---|---|
| `--src` | 源长图（**注意扩展名是 `.jpg`**） |
| `--out` | 输出目录 |
| `--slice` | 每段高度，默认 800；小于 100 直接报错 |
| `--idx` | 章节索引 JSON（提供时输出每段覆盖了哪些章节） |
| `--pad-last` | 把最后一段补成等高（白底） |
| `--format` | 输出格式 |

**清单 JSON 三个全局项**：`width`（目标宽）、`brand_color`（品牌色）、`gap`（**注意：只被写进章节索引，不影响实际间距**）、`divider`（章间真实间距由它控制的 4px 分隔条决定，设 `false` 就完全没有间距）。

## 你会拿到什么

- `详情页长图.jpg` —— 拼合后的整页长图（**扩展名是 `.jpg`，实测确认**）
- `章节索引.json` —— 每章的起止 y、高度、标题、`truncated` 标记（供切图 / 埋点用）
- `拼合报告.md` —— 章节顺序、总高、各章占比
- 切图目录 —— 按 `--slice` 切好的分段图 + `切图清单.json` / `切图清单.md`
- `详情页自检.json` / `详情页自检.md` —— 自检明细与结论（跑 `pdp_check` 后）

### 自检的真实结果（这一条必须如实说）

**两轮 pdp_check 都没通过**，都是 3 项 mid：

| 轮次 | 被点名的章节与近空白行占比 |
|---|---|
| 第一轮（750×7670） | 核心卖点 **81%** / 信任背书 **90%** / 售后保障 **89%** |
| 交付版（750×8664） | 痛点共鸣 **84%** / 信任背书 **85%** / 售后保障 **88%** |

交付版的原始报告原文：

```
详情页自检：750x8664，章节 8，问题 3 项（mid）
  [mid] 非空白章：章节「痛点共鸣」(y=1030~2150) 近空白行占比 84%，疑似视觉断层
  [mid] 非空白章：章节「信任背书」(y=6614~7804) 近空白行占比 85%，疑似视觉断层
  [mid] 非空白章：章节「售后保障」(y=7804~8664) 近空白行占比 88%，疑似视觉断层
```

**这三项没有修掉，也不是缺陷**——是两个检查器口径不同，如实记录如下：

- `pdp_check` 量的是**逐行墨量**（每行几乎只有底色就计一笔），阈值 0.80。整块米色留白 + 大幅实拍/插图的杂志风章节，天然会命中它。
- 另一道版式密度审计（`card_audit`）量的是**最大连续死白带**与墨量分布，这 8 章 **10/10 全部 PASS**：墨量跨度 `span` ≤ 0.890、底部死区 `bottom_dead` ≤ 0.121、最大空带 `max_gap` ≤ 0.136。其中被点名的三章：痛点共鸣 `span 0.885 / fill 0.376`、信任背书 `span 0.885 / fill 0.411`、售后保障 `span 0.845 / fill 0.258`。

**处理方式：保留原始报告，不为了让结论好看去调阈值。** 两份记录都在交付物里（`06_质检与自检/详情页自检/`、`06_质检与自检/card_audit.json`）。**注意信任背书与售后保障两章是两轮都被点名的**——但它们的 `card_audit` 各项在两轮里都 PASS，所以这是同一处口径差异，不是同一处缺陷没修。

## 常见问题 FAQ

**Q1：报「章节图不存在」？**
A：清单里的路径写错。用绝对路径，或相对于清单文件的路径。

**Q2：拼出来某章是空白？**
A：素材图本身是全透明 PNG。工具会自动垫白底；若仍空白则说明图本身没内容。

**Q3：总高比预期矮？**
A：素材宽度大于目标宽度时被等比缩小了，属正常缩放。要保原高就先裁到目标宽。

**Q4：章节顺序不对？**
A：清单里 `items` 的先后**并不是**拼合顺序——默认按 10 个标准章节重排。要按自己写的顺序走，加 `--keep-order`；非标准 `chapter` 键会被排到末尾。

**Q5：切图最后一张很窄？**
A：总高不是切图高整数倍，属正常。加 `--pad-last` 把最后一段补成等高（白底）。

**Q6：`pdp_check` 退出码是 1，是崩了吗？**
A：不是。存在 high / mid 问题时以退出码 1 结束是设计如此，看 `详情页自检.md` 的结论行。只有 low（宽度非 750/800/1242）不影响通过。

**Q7：清单里设的 `gap` 没生效？**
A：`gap` 只被写进章节索引，**不影响实际间距**。章间真实间距由 `divider` 控制的 4 px 分隔条决定；`divider: false` 就完全没有间距（本包实测就是这么设的，所以总高刚好等于各章高度之和）。

**Q8：切图清单的「覆盖章节」列全是 `-`？**
A：导出时没传 `--idx 章节索引.json`。传上它才会写出每段覆盖的章节。

**Q9：重做时它说「产物已存在（防覆盖）」？**
A：防覆盖是硬中止。目标目录已有 `详情页长图.jpg`、或切图段重名，都会退出。换输出目录或先清空旧目录。

**Q10：某一章图缺失会怎样？**
A：**阻断整次拼合，不跳章继续**。同理 `items` 为空、`--width` < 200、`--slice` < 100 都直接报错退出。

## 注意

- 命令是裸文件名，必须先切到技能目录的 `scripts/` 下或补全路径；依赖 **Pillow**。
- **拼合产物扩展名是 `.jpg` 不是 `.png`**（实测确认）。`pdp_export --src` 要按实际扩展名写；`pdp_check` 对 jpg/png 两种都能找，但 `pdp_build` 只写 jpg。
- **防覆盖是硬中止**：目标目录已有 `详情页长图.jpg` 报「产物已存在（防覆盖）」退出；切图段同名报「产物重名」退出。重做要换输出目录或先清空。
- **任一章节图缺失会阻断整次拼合**（不跳章继续）；`items` 为空、`--width` 小于 200、`--slice` 小于 100 同样直接报错退出。
- 清单里的 `gap` **只被写进章节索引，不影响实际间距**；章间真实间距由 `divider` 控制的 4 px 分隔条决定，设 `false` 就完全没有间距。清单设了 `max_height` 时放不下的章会被截断并在索引里标「已截断」。
- `pdp_check` 存在 high / mid 问题时以**退出码 1** 结束，这是「自检没过」不是「脚本崩溃」，看 `详情页自检.md` 的结论行；只有 low（宽度非 750/800/1242）不影响通过。
- **空白章阈值是「接近纯色的行占比 > 80%」**，大段纯色留白可能被记 mid；高度不足 20 px 的章不做该检查。这是该指标对「大图为主」章节的固有敏感度，不是你的图坏了——用 `card_audit` 一类量死白带的口径交叉复核再下结论。
- 非标准 `chapter` 键会排到末尾；想按清单原序走要显式加 `--keep-order`。
- 本技能没有 `EASEL-META.md`（技能自带 frontmatter 的 `license: MIT` 已够用）。
