# 商品图抠图与去背景

> 不用绿幕、不用钢笔工具：AI 语义分割直接把主体抠出来，出透明底、白底或换场景底。

## 这个技能能做什么

- **透明底**：抠完输出 `.png`，可直接放进任何设计稿
- **电商白底**：`--bg-color white`，一次出可上传的白底主图
- **换场景底**：`--bg-image scene.jpg`，自动等比覆盖裁切后合成
- **人像精细档**：`--model u2net_human_seg --alpha-matting`，处理头发、毛绒边缘

五个可选模型对应不同精度：

| 模型 | 适用 |
|---|---|
| `u2net`（默认） | 通用主体，全质量档 |
| `u2netp` | 轻量快速，质量略低 |
| `u2net_human_seg` | 人像专用 |
| `isnet-general-use` | 更精细的通用分割 |
| `silueta` | 体积小的通用模型 |

## 什么时候用它

- 实拍图背景杂乱，要换成统一的白底做商品主图
- 要把商品放进场景图里做使用场景图
- 要出透明底 PNG 放进详情页设计稿
- 人像、模特图要抠出来换背景

| 材料 | 说明 | 必需 |

| 图片 | 要抠图的图片（没给就问） | 是 |

| 模型 | 通用 / 人像 / 精细，见上表 | 否 |

**环境**：脚本随「电商美工公共运行库」提供，装到 `C:\Users\<你>\.qoder\shared\scripts\` 下即可用。首次运行会自动下载模型（视模型而定，约 4–170 MB，u2net 约 168 MB），需要外网；脚本读 `EASEL_PROXY` / `http(s)_proxy`，未设则直连。

## 操作步骤

### 第 1 步：环境自检

```bash
python C:\Users\<你>\.qoder\shared\scripts\remove_bg.py check
```

### 第 2 步：按用途选一条命令（整条写成一行，去掉折行符）

```bash
# 透明背景（务必输出 .png）
python ...\remove_bg.py remove -i product.jpg -o outputs\主题名\cutout.png

# 电商白底主图
python ...\remove_bg.py remove -i product.jpg -o outputs\主题名\white.jpg --bg-color white

# 换新场景背景
python ...\remove_bg.py remove -i person.jpg -o outputs\主题名\scene.png --bg-image scene.jpg

# 人像 + 毛发边缘细腻
python ...\remove_bg.py remove -i portrait.jpg -o outputs\主题名\cut.png --model u2net_human_seg --alpha-matting
```

### 第 3 步：目检（换景产物必做）

透明底与白底可以凭肉眼粗看；**换场景底的产物必须逐张目检再用**——脚本不会报警（原因见「注意」一节的环形商品实测）。

## 完整对话案例

### 案例：6 张实拍图抠成透明底，再用白底出主图

**你说：** 这 6 张马克杯实拍图背景太乱，帮我抠成透明底，另外用白底出一版做主图。

**它做：**

```bash
python C:\...\remove_bg.py check
python C:\...\remove_bg.py remove -i 原料\p1.jpg -o outputs\屿陶马克杯\抠图\p1.png
python C:\...\remove_bg.py remove -i 原料\p1.jpg -o outputs\屿陶马克杯\白底\p1.jpg --bg-color white
# ……其余 5 张同理
python C:\...\image_ops.py info -i outputs\屿陶马克杯\白底\p1.jpg
```

**你会看到：**

```
✅ outputs\屿陶马克杯\抠图\p1.png  (1259x1495, 透明通道)
✅ outputs\屿陶马克杯\白底\p1.jpg  (1259x1495, 214KB)
```

### 接着它做了一件你没让它做的事（实测价值就在这里）

**它目检发现轮廓有一圈偏白的灰边**——因为原图是白底拍摄，掩膜是二值硬边，最外一圈像素还带着白底颜色，贴到米色纸面上就发白。

**修法：** alpha 通道腐蚀 2px + 0.7px 高斯恢复抗锯齿，只动掩膜不动像素。

**复核结果：** 过渡带像素 0 → 26465，且过渡带均值亮度 L* = 71.3 / 55.4 / 52.1，**低于**米色底 L* 91.6——轮廓不再比底色更白。

## 常见问题 FAQ

**Q1：输出写 `.jpg` 会不会抠坏？**
A：不会。jpg 不支持透明，脚本会打印提示并自动垫白底。要透明背景必须写 `.png`。

**Q2：`--bg-color` 和 `--bg-image` 能一起用吗？**
A：不能，二选一，同时给会直接报错退出。

**Q3：首次运行报「加载模型失败」是坏了吗？**
A：多半是模型没下载成功。首次运行要联网（u2net 约 168 MB），脚本读 `EASEL_PROXY` / `http(s)_proxy`，没设就走直连。设好代理重跑即可。

**Q4：耳环、戒指这类镂空商品为什么抠完换场景会露白块？**
A：**环形 / 有孔洞的商品要特别当心（实测）**：拍在白色台面上的耳环、戒指、镂空件，孔洞里的背景会被模型当成主体一起保留，alpha 是二值的（实测非零像素 8.6%–11.2%，半透明像素 0%）。垫白底当主图看不出来，但一旦 `--bg-image` 换场景，孔里那块白背景就会露出来变成白色色块，商品像浮在场景上。这类图请自己先抠好再喂，或者放弃换景、直接用实拍原图裁切当场景图。

**Q5：`--alpha-matting` 让脚本崩了？**
A：**在本机实测会崩**：810×1080 的实拍图上跑 u2net + `--alpha-matting` 报 `numpy._core._exceptions._ArrayMemoryError`（rc=1，不是路径或模型问题）。要更细的边缘，先把图缩到 1024 长边以内再开这个开关。

**Q6：缩放、裁切、加水印在哪做？**
A：不在这个技能里。本技能只做抠图与换底，其余归「通用图像处理加工」。

## 注意

- 命令里的行尾 `\` 是技能文档原样的折行写法，Windows 的 CMD / PowerShell 不认；执行时把整条命令写成一行（去掉 `\`）。
- 本脚本随「电商美工公共运行库」提供：把 `ecom-shared-runtime.zip` 里的脚本装到 `C:\Users\<你>\.qoder\shared\scripts\` 下即可用，命令里的 `skills/shared/scripts/remove_bg.py` 换成该绝对路径就能跑；六个脚本互不依赖，缺哪个补哪个。
- 首次运行要联网下载模型，脚本读 `EASEL_PROXY` / `http(s)_proxy`，没设就走直连；下载失败会报「加载模型失败」，不是脚本坏了。
- 要透明背景必须输出 `.png`；写成 `.jpg` 会打印提示并自动垫白底，别当成抠坏了。
- `--bg-color` 与 `--bg-image` 二选一，同时给会直接报错退出；`--model` 只认上面那五个名字，写错命令行拒绝执行。
- 抠图质量取决于主体与背景的对比度：背景复杂、低对比、主体与背景同色时无法保证完美边缘。
- **环形 / 有孔洞的商品要特别当心（实测）**：拍在白色台面上的耳环、戒指、镂空件，孔洞里的背景会被模型当成主体一起保留，alpha 是二值的（实测非零像素 8.6%~11.2%，半透明像素 0%）。垫白底当主图看不出来，但一旦 `--bg-image` 换场景，孔里那块白背景就会露出来变成白色色块，商品像浮在场景上。这类图请自己先抠好再喂，或者放弃换景、直接用实拍原图裁切当场景图。换景产物必须目检再用，脚本不会报警。
- **`--alpha-matting` 在本机实测会崩**：810×1080 的实拍图上跑 u2net + `--alpha-matting` 报 `numpy._core._exceptions._ArrayMemoryError: Unable to allocate 1.86 GiB for an array with shape (250000000,)`（rc=1，不是路径或模型问题）。要更细的边缘，先把图缩到 1024 长边以内再开这个开关，别直接在高清原图上开。
- 只做抠图与换底：缩放、裁切、加水印、压大小、拼图都归「通用图像处理加工」，别在抠图命令里找这些参数。
- 脚本不校验输出路径，`outputs/主题名/` 是技能约定；父目录会自动创建，但主题名请写具体（别用 test、临时）。
