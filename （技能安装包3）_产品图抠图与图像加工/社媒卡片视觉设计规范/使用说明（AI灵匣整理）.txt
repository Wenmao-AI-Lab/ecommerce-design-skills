# 社媒卡片视觉设计规范

> 高级感来自「克制 + 层级 + 网格 + 填满」，不是靠阴影 / 圆角 / 渐变堆出来的。「没人做设计决定」= AI 选了一万张图的统计平均值 = 廉价，这套系统就是替你把决定钉死。

## 这个技能能做什么

**它是设计系统 + 硬规则，不是生成器。** 所有「HTML / CSS → 截图」的卡片与海报技能，在写第一行 HTML 之前先读它。

五步流程（照做，别跳）：

1. **让用户选风格**（第一步也是最重要的一步）——风格库现有 9 种：瑞士极简 / 杂志编辑 / 新中式墨韵 / 奶油温柔 / 多巴胺 Y2K / 高奢黑金 / 手账贴纸 / 极客终端 / 植物清新。用户没指定就列 3–4 个候选让 ta 挑。**卡片美不美，第一取决于选对风格。**
2. **锁定该风格的 spec** ——字体（family + 字重）+ 配色 hex + 版式性格 + 装饰，整套卡片全程只用这一套，不自由发挥、不换色。
3. **定字体层级** ——「**字越大越细**」，大标题用 Thin / Light 字重；手机端正文 ≥28px。
4. **套骨架** ——从卡型骨架（封面 / 账本 / 管线 / 对比 / 矩阵 / 数据 / 金句）选一个，按其最小密度线填内容。
5. **渲染后自检（硬门禁）** ——`card_audit.py audit`，任何 FAIL 就按「欠填修正阶梯」补内容或换骨架**重渲**，全 PASS 再交付。

六条铁律：**填满**（内容覆盖 ≥75% 画高，无理由空白带 >15% 画高即失败）· **字越大越细** · **禁 emoji 当图标**（用 Lucide 线性图标 stroke 1.5）· **禁蓝紫科技渐变**（头号 AI tell）、禁渐变字、禁玻璃拟态 · **正文永不用纯黑**（用深灰 / 深墨）· 瑞士立场零圆角零阴影禁渐变，杂志立场小圆角 + 极柔阴影 + 背景氛围层。

## 什么时候用它

- 做出来的卡片 / 海报「能看但不好看」，想找出具体问题
- 卡片底部大片空白填不满，或内容头重脚轻
- 配色凭感觉选，一套图里换了好几种风格
- 文案写好了要出小红书封面、金句卡、知识卡
- 接到别的技能出的图，想在下发之前先过一遍视觉质检

## 操作步骤

### 第 1 步：选风格并锁 spec

从 `references/styles.md` 的九种命名风格里选一个。用户已指定就直接用；没指定就列 3–4 个候选（风格名 + 一句话 + 适用）让 ta 挑，急着要就用推荐的第一个并说明「默认用了 X 风格，想换随时说」。

风格选定后，字体 + 配色 + 版式性格 + 装饰四项**全部照 spec 用**，全程不换。

### 第 2 步：定字体层级

按 `references/typography.md`：**字越大越细**。字体已装 Noto Sans / Serif CJK 全字重，大标题用 Thin / Light；手机端正文 ≥28px。

### 第 3 步：套骨架填内容

从 `references/card-recipes.md` 选卡型骨架，按其**最小密度线**填内容（封面 / 账本 / 管线 / 对比 / 矩阵 / 数据 / 金句）。

### 第 4 步：渲染

出图走公共库的 `render_card.py`（HTML → PNG）：

```bash
python C:\Users\<你>\.qoder\shared\scripts\render_card.py --html card.html --out card.png --full-page --width 1080 --height 1440
```

### 第 5 步：硬门禁自检（必做）

```bash
python C:\Users\<你>\.qoder\skills\card-design\scripts\card_audit.py audit -f outputs\主题名\card_*.png
```

任何 FAIL（死空白 / 跨度不足 / 头重脚轻）→ 按 `references/layout-laws.md` 的「欠填修正阶梯」补内容或换骨架**重渲**，全 PASS 再交付。

## 命令速查

| 命令 | 用途 |
|---|---|
| `card_audit.py audit -f 图.png` | 版式密度质检（span / 死空白 / 最大空带 / 四带分布） |
| `card_audit.py audit -f 图*.png --json` | 输出 JSON 结果 |
| `card_audit.py selftest` | 自检（含负向对照样例） |
| `card_audit.py audit --tol 0.15` | 容差参数（**当前不影响判定结果**，见「注意」） |
| `render_card.py --html x.html --out x.png --full-page --width 1080 --height 1440` | 渲染出图（公共库脚本） |

## 你会拿到什么

## 完整对话案例

### 案例：一版小红书知识卡被判 FAIL 之后

**你说：** 这是我做的知识卡，老板说「看着像 PPT」，帮我看看哪里不对。

**它做：**

```bash
python C:\...\card-design\scripts\card_audit.py audit -f 卡片.png
```

**结果是：**

```
{
  "label": "知识卡", "size": "1080x1440", "bg": [238, 228, 208],
  "span": 0.62,            ← 内容只覆盖 62% 画高（要求 ≥0.75）
  "bottom_dead": 0.22,     ← 底部 22% 是死空白
  "max_gap": 0.19,         ← 中段有一条 19% 画高的空带（阈值 15%）
  "fill": 0.21,
  "bands": [0.41, 0.09, 0.18, 0.22],
  "pass": false,
  "problems": ["中段最大空白带 19% > 15%", "底部死空白 22% > 15%"]
}
```

**它接着按「欠填修正阶梯」给动作：**

1. 把三条论断改成四条，每条补一个具体数字（不是加装饰填空）
2. 底部空出的一块挂上「来源 / 数据口径」小字块，顺势把底部补满
3. 栏目间距由均匀 48px 改成分组间距 64px、组内 24px，消除中段空带
4. 重渲后重跑 `card_audit`，直到全 PASS

**重渲复核：** `span 0.89 / bottom_dead 0.051 / max_gap 0.132 / fill 0.393 / pass true`

### 案例 2（实测中真踩到的坑）

**它给你一张白底商品图当封面时，会主动警告你：**

> 白底商品图会把质检打 FAIL——`card_audit` 判死空白看的是内容覆盖带，白底 packshot 用 `background-size: contain` 铺进固定高度图框时，图四周的白被算成空洞，报「中段最大空白带 >15%」。先紧裁到内容外接框再铺，或让图框高度随图自适应。

实测 7 张详情页章节卡 + 1 张海报按此返工后 **0 FAIL**。

## 常见问题 FAQ

**Q1：`--tol` 调大能不能把 FAIL 变 PASS？**
A：**不能**。该参数当前不影响判定结果——脚本内部按固定阈值算（相邻像素差 >12、单行边缘占比 >0.6% 记为有内容）。想靠调它过关是徒劳的。

**Q2：白色商品图为什么会被判死空白？**
A：因为质检判的是「内容覆盖带」，白底 packshot 四周的白被当成空洞。先把商品图紧裁到内容外接框再铺（用「通用图像处理加工」的 `crop` 按坐标裁），或让图框高度随图自适应。

**Q3：我就想要大面积留白的高级感，它非要我填满？**
A：填满法则针对的是**无理由**空白。空白有功能（分组、呼吸、视觉重心）就不算死空白。规则是「任何无理由空白带 >15% 画高 = 失败」，内容少时正解是扩内容 / 换省高骨架 / 换 1:1 画幅。

**Q4：它是不是会自己出图？**
A：不是。它是**设计约束**，不是渲染器。最终出图靠公共库 `render_card.py`。

**Q5：为什么我传了图它说「图片不存在」？**
A：glob 没匹配到文件时，脚本会把整串当文件名去读。先确认 `--out-dir` 与文件名前缀。

**Q6：没有账号 Profile 会用成什么样？**
A：知识 / 科技类默认「瑞士 + 克莱因蓝」或「杂志 + Indigo Porcelain」；生活 / 情感类默认「杂志 + Kraft / Dune 暖纸」。有 Profile 时从 `style.md` 读品牌配色，但**优先保证本系统的高级感底线**——Profile 没给明确视觉规范时，按本系统选立场锁色，不退回「柔和渐变」这类模糊描述。

## 注意

- **白底商品图会把质检打 FAIL**：`card_audit` 判死空白看的是内容覆盖带，白底 packshot 用 `background-size: contain` 铺进固定高度图框时，图四周的白被算成空洞 → 报「中段最大空白带 >15%」。先把商品图紧裁到内容外接框（用「通用图像处理加工」的 crop 按坐标裁）再铺，或让图框高度随图自适应。
- 纯渐变底不算内容：竖向平滑渐变没有横向边缘，会被判成空白，装饰层填不满画幅。
- `--tol` 参数当前不影响判定结果（脚本内部按固定阈值算：相邻像素差 >12、单行边缘占比 >0.6% 记为有内容），想靠调它把 FAIL 变 PASS 是徒劳的。
- glob 没匹配到文件时，脚本会把整串当文件名去读并报「图片不存在」，先确认 `--out-dir` 与文件名前缀。
- 本技能是设计约束，不是渲染器；最终出图仍靠公共库 `render_card.py`（装到 `C:\Users\<你>\.qoder\shared\scripts\` 下即可用）。
- 命令里的 `skills/openclaw/...` 是技能文档的原始路径写法，装好后脚本实际在 `C:\Users\<你>\.qoder\skills\card-design\scripts\card_audit.py`，两种写法等价。
- 产物按本包统一布局落 `outputs/<具体主题>/`：主题名必须是具体名字，写 `output`、`test`、`临时`、`主题名` 这类泛名会被公共库 `output_paths.py` 直接拒写（同包的动画图表脚本就硬校验）。
